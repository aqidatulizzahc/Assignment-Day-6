# 🐱 Cuking LMS - LMS Perawatan Kucing

Landing page untuk **Cuking LMS**, platform Learning Management System (LMS) yang berfokus pada dunia kucing. Pelajari cara merawat, melatih, dan memahami perilaku kucing melalui kursus interaktif yang disusun oleh dokter hewan dan pecinta kucing berpengalaman.

## Fitur Utama

- **Cat Care** – Materi dari dasar hingga lanjutan, mulai dari nutrisi hingga kesehatan kucing.
- **Decoding Cat Behavior** – Video, kuis, dan studi kasus untuk memperdalam pemahaman.
- **Feline Nutrition Basics** – Dapatkan sertifikat setelah menyelesaikan kursus.

## Tech Stack

HTML dan CSS

## Cara Menjalankan

1. Clone repositori ini
2. Buka `index.html` di browser Anda
